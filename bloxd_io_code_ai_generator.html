How to use scripts in Bloxd.io

Step-by-step guide to running your custom AI scripts

  1. Open your custom world in Bloxd.io (Creative mode or owner permissions required).
  2. Search your inventory for the Code Block item and place it down.
  3. Right-click or press interact key on the Code Block to open its script editor.
  4. Click "Copy Code" on this website to copy your AI generated code.
  5. Paste the code into the Bloxd Code Block editor and click Save / Apply.
